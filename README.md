
# 🏋️ FitTrack

A modern fitness tracking dashboard built with **React + Vite** that helps users stay consistent with their health and fitness goals.

## 🌐 Live Demo

https://fittrack-tau-self.vercel.app/

---

## ✨ Features

### 👤 User Profile

* Add and edit personal details
* Track weight and height
* Set fitness goals:

  * Muscle Gain
  * Fat Loss
  * Maintenance

### 📊 BMI Calculator

* Automatically calculates BMI from height and weight
* Displays BMI category:

  * Underweight
  * Normal Weight
  * Overweight
  * Obese

### 🍗 Protein Tracker

* Set a daily protein goal
* Track protein intake
* Visual progress bar

### 💧 Water Tracker

* Set a daily water intake goal
* Track water consumption
* Visual progress bar

### 🔥 Streak System

* Earn streaks by completing all daily goals
* Maintains consistency tracking across sessions

### 🏅 XP & Level System

* Gain XP through goal completion
* Level up as you progress
* Visual XP progress bar

### 🏆 Achievement System

Unlock achievements such as:

* First Workout
* Hydration Hero
* Protein Master
* Consistency Beast

### 📅 Workout Planner

* Customize workout schedules for each day of the week
* Edit and save workout plans

### 📝 Daily Notes

* Write daily workout reflections
* Save notes locally

### 📈 Weekly Progress Tracking

* Monitor daily goal completion
* Visualize weekly consistency

### 🌙 Dark Mode

* Toggle between Light and Dark themes
* Improved user experience and accessibility

## 🚀 Installation

Clone the repository:

```bash
git clone <your-repository-url>
```

Move into the project folder:

```bash
cd fittrack
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
